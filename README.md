This is a daily report which tracks specific repos for updates.

I use some of these directly and maintain forks of others. This is the easiest way for me to track all of them and stay updated.

Fairly easy to replicate for yourself, requires a Discord WebHook in secrets, outside that just trigger the action with a remote cron job and you're good to go. This pushes a message to a Discord channel of your choice.
